# Synapse ⚡

**Tiny Trivia, Big Curiosity**

Feed your mind in under 5 seconds with Synapse, the micro-trivia app designed for quick bursts of curiosity. Every time you open the app, discover a fascinating fact that sparks your imagination and makes you see the world differently.

## ✨ Features

- **⚡ Quick Trivia Snacks** – Learn amazing facts in seconds, no long reading required
- **💡 Daily Mind Sparks** – Open Synapse anytime for a small curiosity boost
- **🌍 Wide Variety of Facts** – From science and nature to history and quirky oddities
- **🎨 Minimal & Clean Design** – Focus on the fact itself, without distractions
- **🔄 Infinite Curiosity** – Keep exploring tiny trivia whenever you want a brain boost
- **🌙 Dark Mode Support** – Easy on the eyes, day or night
- **🎭 Smooth Animations** – Fluid, delightful user experience
- **👆 Swipe Gestures** – Natural interaction for browsing facts

## 🎨 Design Philosophy

Synapse features a modern, sleek Material 3 design with:
- Beautiful gradient backgrounds
- Smooth spring animations
- Category-coded color badges
- Minimalist, distraction-free interface
- Edge-to-edge immersive experience

## 🏗️ Technical Architecture

Built with cutting-edge Android development practices:

### Technologies
- **Kotlin** - Modern, concise, and safe
- **Jetpack Compose** - Declarative UI toolkit
- **Material 3** - Latest Material Design components
- **ViewModel** - State management with lifecycle awareness
- **StateFlow** - Reactive data streams
- **Coroutines** - Asynchronous programming

### Project Structure
```
app/
├── data/               # Data layer
│   ├── TriviaFact.kt  # Data models
│   └── TriviaRepository.kt  # Data source
├── viewmodel/         # Business logic
│   └── TriviaViewModel.kt
├── ui/
│   ├── components/    # Reusable UI components
│   │   ├── TriviaCard.kt
│   │   └── SplashScreen.kt
│   └── theme/         # Design system
│       ├── Color.kt
│       ├── Theme.kt
│       └── Type.kt
└── MainActivity.kt    # App entry point
```

## 🚀 Getting Started

### Prerequisites
- Android Studio Ladybug or later
- Android SDK 24 or higher
- Kotlin 2.0+

### Build & Run
1. Clone the repository
2. Open in Android Studio
3. Sync Gradle dependencies
4. Run on emulator or physical device
